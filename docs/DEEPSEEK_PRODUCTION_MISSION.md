**This is a hero feature. Implement it as a real coded animation, not a static image or fullscreen blocking video.**

Visitor sequence (reference timing, tune after profiling; ~2.2–2.8 seconds total on capable devices):
- 0–180ms: deep navy stage, very subtle champagne horizon, logo not yet visible; accessible skip control remains immediately present.
- 180–650ms: multiple delicate golden light threads arc into frame, matching the *approved original logo's* silhouette contours. Threads trace hair and the profile through hand-tuned SVG strokes, masks and stroke-dasharray/offset with path lengths; motion is smooth and premium.
- 650–1050ms: metallic microphone contour and audio waveform progressively connect to the moving linework. Subtle lotus and Egyptian accent emerge naturally, no random symbols.
- 1050–1480ms: threads converge/morph via opacity/mask into **the actual approved logo PNG**, not an AI approximation. Blend physically grounded glints, no white flash.

- 1900–2600ms: the mark transitions smoothly into the nav brand while the real home hero enters; never blank the screen to wait for a media download.

**Technical contract:**
- React component: BrandThreadSplash; isolate animation code/data from core routing.
- Prefer inline SVG, CSS and Motion for React for path animation; user-supplied transparent raster logo is revealed at the end.
