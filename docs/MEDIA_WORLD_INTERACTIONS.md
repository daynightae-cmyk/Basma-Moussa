## C. Door / portal behavior (genuine navigation)
1. Clickable portal cards display cover, bilingual title, teaser, real publication status and a standard link.
2. Hover/focus adds gentle layered depth and gold rim; mobile retains obvious CTA without hover.
3. On click, selected card's image expands into stage using shared-element geometry; curved door panels part over 650–950ms, with gold filament light entering a new world.
4. Real route changes, maintains history, keyboard semantics, deep links and browser Back; the new world appears with heading and focus control.
5. A clear "Back to Universe" link is present; reduced-motion directly navigates or uses simple fade.
6. If motion JS fails, use normal anchor navigation. If route/data missing, show true retry/back state; never trap user behind overlay.
